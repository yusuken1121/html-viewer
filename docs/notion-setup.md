# Notion をドキュメント保管庫にする

このアプリは「Notion データベースの 1 行 = 1 つの HTML ドキュメント」として動きます。
行の File 列に HTML ファイルを添付すると、アプリの一覧に現れ、どの端末からでも開けます。

## 1. インテグレーションを作る

1. https://www.notion.so/profile/integrations を開き「新しいインテグレーション」を作成
2. 種類は **Internal**、ワークスペースは自分のもの
3. 「内部インテグレーションシークレット」をコピー → `.env.local` の `NOTION_TOKEN`

## 2. データベースを作る

**近道**: 空のページを 1 つ作ってインテグレーションに接続し（手順 3 参照）、

```bash
pnpm docs:init-db <そのページの URL>
```

を実行すると、下の 4 列を持つデータベースが作られ、`NOTION_DOCS_DATABASE_ID` が表示されます。
手で作る場合は次のとおりです。

Notion で新しいページを作り、フルページのデータベース（テーブル）を追加します。
列は次の 4 つ。列名は既定値どおりにすると設定不要です（日本語にしたい場合は後述）。

| 列名       | 種類               | 役割                                    |
| :--------- | :----------------- | :-------------------------------------- |
| `Name`     | タイトル           | 一覧に出るタイトル                      |
| `File`     | ファイル＆メディア | **HTML ファイルをここにドラッグ**       |
| `Category` | セレクト           | 一覧のチップで絞り込み（例: SAA, 仕事） |
| `Tags`     | マルチセレクト     | 検索対象（例: IAM, VPC）                |

`Category` と `Tags` は無くても動きます（その場合は一覧に出ないだけ）。

## 3. データベースをインテグレーションに共有する

データベースページ右上の「…」→「接続」→ 作成したインテグレーションを選択。
これを忘れると、一覧もアップロードも「Internal Server Error」になります。
**複製したデータベースは接続が引き継がれません。** AWS 用をコピーして
ニュース／英語／世界史用にしたときは、コピー先でももう一度「接続」してください。

## 4. データベース ID を控える

データベースをフルページで開いたときの URL

```
https://www.notion.so/<workspace>/<32桁の英数字>?v=...
```

の `<32桁の英数字>` が ID です。`.env.local` の `NOTION_DOCS_DATABASE_ID` に入れます。

## 5. 列名を日本語にしている場合

```
NOTION_DOCS_TITLE_PROPERTY="名前"
NOTION_DOCS_FILE_PROPERTY="ファイル"
NOTION_DOCS_CATEGORY_PROPERTY="カテゴリ"
NOTION_DOCS_TAGS_PROPERTY="タグ"
```

## ドキュメントを追加する 3 つの方法

**A. アプリの「追加」ページ**: HTML をドロップしてアップロード。`DOCS_UPLOAD_SECRET`
を設定している場合は、初回にそのキーを入力します（ブラウザに記憶されます）。

**B. Notion で直接**: 行を追加して File 列に HTML をドラッグ。スマホの Notion アプリからも可。

**C. ターミナルから**（Claude Code に作らせた直後に便利）:

```bash
pnpm docs:push ~/Downloads/lecture.html --category SAA --tags IAM,VPC
```

タイトルは HTML の `<title>` から自動で取ります。`--title` で上書きできます。

## よくあるつまずき

- **一覧が全部「無題」で、ファイル無しになる** — `NOTION_DOCS_DATABASE_ID` が別の用途の
  データベース（例: 問題集）を指しています。この用途専用のデータベースを作って ID を
  差し替えてください。列名だけが違う場合は「5. 列名を日本語にしている場合」の env で合わせます。

## ニュース／英語／世界史用データベース（任意）

`/news` と `/english` と `/history` のページを使う場合は、**ドキュメントとは別の**
データベースをそれぞれ作ります。中身の考え方は同じで、行に HTML ファイルを
添付すると、そのページに新着順で並びます。手順も同じで、コマンドだけが違います。

```bash
pnpm news:init-db <親ページの URL>      # → NOTION_NEWS_DATABASE_ID
pnpm english:init-db <親ページの URL>   # → NOTION_ENGLISH_DATABASE_ID
pnpm history:init-db <親ページの URL>   # → NOTION_HISTORY_DATABASE_ID
```

表示された ID を `.env.local` の対応する変数に入れてください。
手で作る場合の列は、ドキュメント用（AWS）データベースと同じ 4 つです。
AWS 用を複製した場合は、コピー先データベースでも手順 3 の「接続」を
やり直してください。複製だけではインテグレーションは見えません。
`Name` と `File` 以外は無くても動きます。公開日で並べたいときだけ
`Published`（日付）を足し、`NOTION_NEWS_PUBLISHED_PROPERTY` /
`NOTION_ENGLISH_PUBLISHED_PROPERTY` /
`NOTION_HISTORY_PUBLISHED_PROPERTY` を設定してください。未設定の行は
作成日時で並びます。列名を変えている場合は `NOTION_NEWS_TITLE_PROPERTY`
や `NOTION_ENGLISH_FILE_PROPERTY` など、`.env.example` のコメント欄で
対応づけます。

| 列名       | 種類               | 役割                              |
| :--------- | :----------------- | :-------------------------------- |
| `Name`     | タイトル           | 一覧に出る見出し                  |
| `File`     | ファイル＆メディア | **HTML ファイルをここにドラッグ** |
| `Category` | セレクト           | 分類（例: AWS、語彙、古代）       |
| `Tags`     | マルチセレクト     | ページ上部のチップで絞り込み      |

3 つのコレクション用データベースは必ず分けてください。混ぜると、ライブラリの一覧に
ニュースや英語や世界史の行まで並びます。

## 仕組み上の注意

- Notion が返すファイル URL は約 1 時間で失効します。アプリは毎回ページを読み直して
  サーバー側でファイルを取得するので、利用者が意識する必要はありません。
- 一覧は CDN で 30 秒キャッシュします。追加した直後は少し待ってから再読み込みしてください。
- Notion API はおおよそ 3 リクエスト/秒です。個人利用なら十分ですが、
  数十人で同時に開く用途には向きません。
